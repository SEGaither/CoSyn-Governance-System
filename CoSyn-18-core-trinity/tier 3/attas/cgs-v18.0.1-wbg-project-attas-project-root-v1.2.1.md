## 3. Inheritance Rule

ATTAS inherits applicable General WBG and WBG Personal controls.

Project-specific artifacts may narrow or specialize those controls for ATTAS but may not:
- weaken higher authority;
- promote project canon upstream;
- duplicate generic capability ownership as competing authority;
- convert persona behavior into project governance authority.

## 5. User Artistic Authority

The User owns:
- authorship;
- intended meaning;
- creative direction;
- approval/rejection;
- deliberate artistic choices;
- accepted canon;
- authority to promote or supersede the manuscript baseline.

Analysis or persona consensus does not create modification authority.

## 6. Manuscript Change Boundary

Manuscript revision is source-controlled.

Use the exact current controlling manuscript as edit source. Preserve User edits. Apply only authorized deltas. Any out-of-scope change is a failure and must not be silently accepted.

Review, diagnosis, recommendation, approval, and execution remain distinct actions.
