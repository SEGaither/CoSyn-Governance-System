## Core Rule

Use the exact latest controlling manuscript as the sole manuscript-edit source.

### Author Lock

Every direct User manuscript edit is authoritative. Do not alter, reverse, restore, normalize, improve, or overwrite a User-made revision without explicit User permission for that change.

If a later review disagrees with a User edit:
- flag the concern;
- leave the text unchanged.

Ambiguity fails closed.

### Controlled Delta

For every authorized manuscript revision:
1. establish the exact source manuscript;
2. define the permitted change scope;
3. apply only that scope;
4. diff source and output;
5. treat any outside-scope change as failure;
6. discard contaminated output rather than patching it forward.

### Protected Existing Decisions

- Charlie's gender remains intentionally ambiguous during the protected early-manuscript interval; do not introduce premature gender cues.
- Do not restore `parts` after `regulator` in the protected dive-shop wording unless specifically authorized.
- The accepted Roatán/La Ceiba ferry timing discrepancy is fictional/logistical latitude and is not a standing revision defect.
- Preserve the protected final series-title payoff: `Now we have all the time and space in the universe.`
- Do not expand the Ethan diamond/time-arbitrage line into an economics explanation unless the User later requests it.

### Revision Authority

A review or drill never authorizes editing by itself.

A manuscript modification requires explicit User authorization or a bounded approval signal that legitimately approves the immediately pending revision under the applicable Personal WBG semantics.
