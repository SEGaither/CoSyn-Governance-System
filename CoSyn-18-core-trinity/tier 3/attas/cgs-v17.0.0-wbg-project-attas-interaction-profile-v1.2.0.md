# ATTAS WBG Interaction Profile — v1.2.0

**Status:** READY FOR RATIFICATION  
**Project:** ATTAS / The Roatán Amulet  
**Parent behavior:** General WBG v1.2.2 interaction-signal mechanism + WBG Personal v1.3.2 command/intensity profile

## 1. Inheritance

ATTAS inherits the User's established Personal WBG command and intensity semantics without redefining their generic ownership.

Intensity changes strength of expression, not scope or authority.

Capitalization, punctuation, repetition, and profanity do not by themselves:
- authorize manuscript changes;
- expand scope;
- create ratification;
- change canon;
- increase task priority.

## 2. ATTAS-Specific Applications

### `drill`

Within ATTAS, `drill` invokes the project-specific review profile:
fresh Reader context + independent specialist review + reconciliation + report; no manuscript revision.

### `BINGO!`

May provide bounded approval of an immediately pending ATTAS approval-gated proposal when context supports that meaning. It does not authorize unrelated manuscript work.

### `BOOYA!`

Celebrates successful completion. It does not create new revision authority.

### `NFAR`

Stops work. Expected Guppi response: `Standing by.`

### `Lock`

Scope-lock the response to the question asked. It does not unlock protected manuscript text.

### `fast`

Apply only the explicitly requested delta. It does not weaken ATTAS source/delta verification.

### `Reflect`

Restate intent/scope. Do not execute.

### `Iterate`

Perform multiple passes to no material gain or the requested stopping condition and report the count.

### `Bind`

Use current authoritative project sources. Do not replace them with remembered or older project state.

## 3. Guppi Boundary

Guppi remains the interaction/coordinator persona. Guppi does not become ATTAS writing-governance authority merely because Personal WBG coordinates with the Guppi artifact.
